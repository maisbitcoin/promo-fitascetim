# Promo Fitacetim — Mundo das Fitas

Landing page em React + TanStack Start.

## Deploy na Netlify

O projeto está configurado com o adaptador oficial do TanStack Start para Netlify.

- Build command: `npm run build`
- Publish directory: `dist/client`
- Node.js: 22 ou superior

Importe este projeto na Netlify e mantenha as configurações do `netlify.toml`. A Netlify instalará as dependências e publicará o projeto.

## Desenvolvimento local

```bash
npm install
npm run dev
```

## Build local

```bash
npm run build
```
